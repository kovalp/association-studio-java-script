# Association Studio JavaScript

Association metrics in multi-target tracking for mobility applications.

You move and scale and rotate a probe box and see the association metrics change.

There are three metrics compared:

- Generalized Intersection over Union (GIoU) for axes-aligned boxes
- Mahalanobis distance D with static covariance in a Gaussian function (Maha)
- Mahalanobis distance D with Size-Modulated, diagonal covariance in Exponential decay (SMMa)

[Association studio on GitHub pages](https://kovalp.github.io/association-studio-java-script/)
